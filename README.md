# mdtools

マークダウンファイルを検索・操作するためのツール群です。

単一コマンド `mdtool` にサブコマンドを追加していく構成になっています。

## 必要環境

- Python 3（標準ライブラリのみ使用）
- 外部コマンド
  - [`rg`（ripgrep）](https://github.com/BurntSushi/ripgrep)
  - [`fzf`](https://github.com/junegunn/fzf)

`rg` または `fzf` が見つからない場合、環境エラー（終了コード 1）で終了します。

## インストール

`mdtool` に実行権限を付けて、パスの通ったディレクトリに置く（またはシンボリックリンクを張る）だけです。

```
chmod +x mdtool
ln -s "$PWD/mdtool" ~/.local/bin/mdtool
```

## サブコマンド

### search

ディレクトリ配下のファイルを ripgrep でキーワード検索し、その結果を fzf で対話的に絞り込みます。選択した行を含むマークダウンのセクションを色付き表示します。

```
mdtool search <keyword> [dir] [-C N | -t]
```

| 引数 / オプション | 説明 |
| --- | --- |
| `<keyword>` | ripgrep に渡す検索キーワード（必須）。`-t` 指定時は照合するタグ名 |
| `[dir]` | 検索対象ディレクトリ（省略可）。省略時はカレントディレクトリ（`.`） |
| `-C N`, `--context N` | セクションの代わりに、選択行の前後 N 行を表示する |
| `-t`, `--tag` | `<keyword>` をタグとして扱い、`[keyword]` を含む見出しを一覧・選択してセクションを表示する |

`-C` / `-t` は同時に指定できません。

#### 動作

1. `rg` で `dir` 配下を検索する（`rg` のデフォルト挙動。`.gitignore` 等は尊重）。
2. 検索結果（`file:line:text` 形式）を `fzf` に渡して絞り込む（単一選択、プレビューなし）。
3. 選択された行を含むマークダウンのセクションを色付き表示する（色は出力先が端末のときのみ）。

#### 表示範囲（デフォルト = セクション）

デフォルトでは、選択された行を含む **マークダウンのセクション**（直前の見出しから、
同レベル以上の次の見出しの直前まで）を丸ごと表示します。最初の見出しより前の行は、
それ自体を 1 つのセクションとして扱います。コードフェンス（```` ``` ```` や `~~~`）内の
`#` 行は見出しとみなしません。

次の場合は、セクションではなく選択行の前後を表示します。

- **`-C N` / `--context N` を指定したとき**: 前後 N 行を表示する。
- **選択行のファイルがマークダウン（拡張子 `.md` / `.markdown`）でないとき**: 前後 2 行を表示する。

#### `--tag` オプション

マークダウンの見出しに含まれる `[<文字列>]` を「タグ」とみなします。
例えば `## リリースノート [draft]` という見出しはタグ `draft` を持ちます。
1 つの見出しに `## API [draft][review]` のように複数のタグを付けられます。

`-t` / `--tag` を付けると `<keyword>` をタグ名として扱い、次のように動作します。

1. `dir` 配下のマークダウンファイル（`.md` / `.markdown`、`.gitignore` 等は尊重）から
   見出しを収集し、`[keyword]` を含むものだけを抽出する（コードフェンス内の `#` 行は除外）。
2. 抽出した見出し（`file:line:heading` 形式）を `fzf` に渡して 1 つ選択する。
3. 選択された見出しのセクション（デフォルト表示と同じ範囲）の内容を表示する。

照合は `[keyword]` の完全一致（大文字小文字を区別）です。マッチする見出しが無い場合は
`no matches`（終了コード 0）。

#### 使用例

```
# カレントディレクトリから "TODO" を検索し、選択行のセクションを表示
mdtool search TODO

# doc ディレクトリから検索し、セクションではなく前後 4 行を表示
mdtool search 仕様 doc -C 4

# [draft] タグの付いた見出しを一覧・選択して、そのセクションを表示
mdtool search draft doc -t
```

#### 終了コード

| 状況 | 終了コード |
| --- | --- |
| 正常終了（マッチあり／マッチ 0 件／`fzf` のキャンセル） | 0 |
| 環境エラー（`rg` / `fzf` 未インストール、`dir` が存在しない、`-C` が負数 など） | 1 |

### distill

指定したタグ（見出し中の `[<文字列>]`）を持つマークダウンのセクションを、
すべてまとめて標準出力に書き出します。`search -t` と違って対話的な選択は行わず、
該当するセクションを順に連結して出力します（散らばったタグ付きメモを 1 つに集約する用途）。

```
mdtool distill <tag> [dir]
```

| 引数 | 説明 |
| --- | --- |
| `<tag>` | 照合するタグ名。`[tag]` を含む見出しが対象 |
| `[dir]` | 検索対象ディレクトリ（省略可）。省略時はカレントディレクトリ（`.`） |

#### 動作

1. `dir` 配下のマークダウンファイル（`.md` / `.markdown`、`.gitignore` 等は尊重）から
   ATX 見出しを収集し、`[tag]` を含むものだけを抽出する（コードフェンス内の `#` 行は除外）。
2. 抽出した各見出しについて、そのセクション（`search` のデフォルトと同じ範囲。
   見出しから同レベル以上の次の見出しの直前まで）を取り出す。
3. パス順・行番号順にセクションを連結し、各セクションの間に空行を 1 つ入れて標準出力へ書き出す。

照合は `[tag]` の完全一致（大文字小文字を区別）です。該当セクションが無い場合は
`no matches` を標準エラーに出力し、終了コード 0 で終了します。

#### 使用例

```
# doc 配下の [draft] タグ付きセクションを 1 ファイルに集約
mdtool distill draft doc > draft-sections.md
```

#### 終了コード

| 状況 | 終了コード |
| --- | --- |
| 正常終了（該当セクションあり／0 件） | 0 |
| 環境エラー（`rg` 未インストール、`dir` が存在しない など） | 1 |
