# mdtools

マークダウンファイルを検索・操作するためのツール群です。

単一コマンド `mdtool` にサブコマンドを追加していく構成になっています。

## 必要環境

- Python 3（標準ライブラリのみ使用）
- 外部コマンド
  - [`rg`（ripgrep）](https://github.com/BurntSushi/ripgrep)
  - [`fzf`](https://github.com/junegunn/fzf)

`rg` または `fzf` が見つからない場合、環境エラー（終了コード 1）で終了します。

## インストール

`mdtool` に実行権限を付けて、パスの通ったディレクトリに置く（またはシンボリックリンクを張る）だけです。

```
chmod +x mdtool
ln -s "$PWD/mdtool" ~/.local/bin/mdtool
```

## サブコマンド

### search

ディレクトリ配下のファイルを ripgrep でキーワード検索し、その結果を fzf で対話的に絞り込みます。選択した行を、前後の文脈付きで色付き表示します。

```
mdtool search <keyword> [dir] [-C N | -s | -t]
```

| 引数 / オプション | 説明 |
| --- | --- |
| `<keyword>` | ripgrep に渡す検索キーワード（必須）。`-t` 指定時は照合するタグ名 |
| `[dir]` | 検索対象ディレクトリ（省略可）。省略時はカレントディレクトリ（`.`） |
| `-C N`, `--context N` | 表示する前後の文脈行数（デフォルト 2） |
| `-s`, `--section` | 選択行を含むマークダウンのセクション全体を表示する |
| `-t`, `--tag` | `<keyword>` をタグとして扱い、`[keyword]` を含む見出しを一覧・選択してセクションを表示する |

`-C` / `-s` / `-t` は同時に指定できません。

#### 動作

1. `rg` で `dir` 配下を検索する（`rg` のデフォルト挙動。`.gitignore` 等は尊重）。
2. 検索結果（`file:line:text` 形式）を `fzf` に渡して絞り込む（単一選択、プレビューなし）。
3. 選択された行を、該当ファイルの前後の文脈付きで色付き表示する（色は出力先が端末のときのみ）。

#### `--section` オプション

`-s` / `--section` を付けると、前後の固定行数ではなく、選択された行を含む
**マークダウンのセクション**（直前の見出しから、同レベル以上の次の見出しの直前まで）
を丸ごと表示します。最初の見出しより前の行は、それ自体を 1 つのセクションとして扱います。
コードフェンス（```` ``` ```` や `~~~`）内の `#` 行は見出しとみなしません。

このオプションはファイルがマークダウン形式（拡張子 `.md` / `.markdown`）のときのみ有効です。
選択行がそれ以外のファイルの場合は、警告を標準エラーに出したうえで通常の文脈表示
（前後 2 行）にフォールバックします。

#### `--tag` オプション

マークダウンの見出しに含まれる `[<文字列>]` を「タグ」とみなします。
例えば `## リリースノート [draft]` という見出しはタグ `draft` を持ちます。
1 つの見出しに `## API [draft][review]` のように複数のタグを付けられます。

`-t` / `--tag` を付けると `<keyword>` をタグ名として扱い、次のように動作します。

1. `dir` 配下のマークダウンファイル（`.md` / `.markdown`、`.gitignore` 等は尊重）から
   見出しを収集し、`[keyword]` を含むものだけを抽出する（コードフェンス内の `#` 行は除外）。
2. 抽出した見出し（`file:line:heading` 形式）を `fzf` に渡して 1 つ選択する。
3. 選択された見出しのセクション（`--section` と同じ範囲）の内容を表示する。

照合は `[keyword]` の完全一致（大文字小文字を区別）です。マッチする見出しが無い場合は
`no matches`（終了コード 0）。

#### 使用例

```
# カレントディレクトリから "TODO" を検索
mdtool search TODO

# doc ディレクトリから検索し、前後 4 行を表示
mdtool search 仕様 doc -C 4

# 選択した行を含むマークダウンのセクション全体を表示
mdtool search 仕様 doc -s

# [draft] タグの付いた見出しを一覧・選択して、そのセクションを表示
mdtool search draft doc -t
```

#### 終了コード

| 状況 | 終了コード |
| --- | --- |
| 正常終了（マッチあり／マッチ 0 件／`fzf` のキャンセル） | 0 |
| 環境エラー（`rg` / `fzf` 未インストール、`dir` が存在しない、`-C` が負数 など） | 1 |
