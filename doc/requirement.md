# 概要

マークダウンファイルを検索・操作するツール群。

- 技術スタック: Python スクリプト（標準ライブラリのみ）
- コマンド体系: 単一コマンド + サブコマンド方式（`argparse` のサブパーサ構成）。今後ツールを追加しやすくする。
- 外部コマンド依存: `rg`（ripgrep）、`fzf`

# ツール

## 1. search

あるディレクトリ配下のファイルを ripgrep でキーワード検索し、その結果を fzf で対話的に絞り込む。結果はファイル名と行番号を含むので、選択した該当行を前後の文脈付きで表示する。

### 使い方

```
mdtool search <keyword> [dir]
```

- `<keyword>`: ripgrep に渡す検索キーワード（必須、コマンド引数）
- `[dir]`: 検索対象ディレクトリ（省略可、コマンド引数）。省略時はカレントディレクトリ（`.`）を対象とする。
- `-C, --context N`: 表示する前後の文脈行数（デフォルト 2）
- `-s, --section`: 選択された行を含むマークダウンのセクション全体を表示する
- `-t, --tag`: `<keyword>` をタグとして扱い、`[keyword]` を含む見出しを抽出・選択してセクションを表示する
- `-C` / `-s` / `-t` は同時に指定できない

### 動作

1. `rg` で `<dir>` 配下の全ファイルを検索する（`rg` のデフォルト挙動。`.gitignore` 等は尊重する）。
2. `rg` の結果（`file:line:text` 形式）を `fzf` に渡して絞り込む。
   - `fzf` の複数選択は不可（単一選択）。
   - `fzf` のプレビューは表示しない。
3. 選択された行について、該当ファイルの該当行を前後の文脈付き（デフォルト 2 行）で色付き表示する。

### `--section` オプション

- `-s` / `--section` を指定すると、前後の固定行数ではなく、選択された行を含む
  マークダウンのセクション全体を表示する。
  - セクションは「直前の ATX 見出し（`#`〜`######`）から、同レベル以上の次の見出しの
    直前まで」とする。最初の見出しより前の行は 1 つのセクションとして扱う。
  - コードフェンス（```` ``` ```` / `~~~`）内の `#` 行は見出しとみなさない。
- このオプションはファイルがマークダウン形式（拡張子 `.md` / `.markdown`）のときのみ有効。
  それ以外のファイルが選択された場合は、警告を標準エラーに出力し、通常の文脈表示
  （前後 2 行）にフォールバックする。
- `-C` と `-s` は同時に指定できない。

### `--tag` オプション

- マークダウンの見出しに含まれる `[<文字列>]` を「タグ」とみなす。
  1 つの見出しに複数のタグ（`## API [draft][review]`）を付けてよい。
- `-t` / `--tag` を指定すると `<keyword>` をタグ名として扱い、以下のように動作する。
  1. `<dir>` 配下のマークダウンファイル（`.md` / `.markdown`、`.gitignore` 等は尊重）から
     ATX 見出しを収集し、`[keyword]` を含むものだけを抽出する。
     - コードフェンス内の `#` 行は見出しとみなさない。
  2. 抽出した見出し（`file:line:heading` 形式）を `fzf` に渡して 1 つ選択する。
  3. 選択された見出しのセクション（`--section` と同じ範囲）の内容を表示する。
- 照合は `[keyword]` の完全一致（大文字小文字を区別する）。
- 抽出結果が 0 件の場合は `no matches`（**exit 0**）。

### 終了コード

- マッチ 0 件、`fzf` のキャンセル（未選択で終了）: **exit 0**
- 環境エラー（`rg` または `fzf` が未インストール、`<dir>` が存在しない 等）: **exit 1**
