# 概要

マークダウンファイルを検索・操作するツール群。

- 技術スタック: Python スクリプト（標準ライブラリのみ）
- コマンド体系: 単一コマンド + サブコマンド方式（`argparse` のサブパーサ構成）。今後ツールを追加しやすくする。
- 外部コマンド依存: `rg`（ripgrep）、`fzf`

# ツール

## 1. search

あるディレクトリ配下のファイルを ripgrep でキーワード検索し、その結果を fzf で対話的に絞り込む。結果はファイル名と行番号を含むので、選択した該当行を前後の文脈付きで表示する。

### 使い方

```
mdtool search <keyword> [dir]
```

- `<keyword>`: ripgrep に渡す検索キーワード（必須、コマンド引数）
- `[dir]`: 検索対象ディレクトリ（省略可、コマンド引数）。省略時はカレントディレクトリ（`.`）を対象とする。
- `-C, --context N`: 表示する前後の文脈行数（デフォルト 2）

### 動作

1. `rg` で `<dir>` 配下の全ファイルを検索する（`rg` のデフォルト挙動。`.gitignore` 等は尊重する）。
2. `rg` の結果（`file:line:text` 形式）を `fzf` に渡して絞り込む。
   - `fzf` の複数選択は不可（単一選択）。
   - `fzf` のプレビューは表示しない。
3. 選択された行について、該当ファイルの該当行を前後の文脈付き（デフォルト 2 行）で色付き表示する。

### 終了コード

- マッチ 0 件、`fzf` のキャンセル（未選択で終了）: **exit 0**
- 環境エラー（`rg` または `fzf` が未インストール、`<dir>` が存在しない 等）: **exit 1**
